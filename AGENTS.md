# Agent Guidelines for rgametoy

Rust Game Boy emulator project focused on DMG model with T-Cycle accuracy.

## Requirements
* A well-structured and rigorous project architecture
* Implement the core emulator logic within the project itself, without using third-party libraries
* Strive for the most accurate possible simulation of actual runtime behavior
* Use T-cycle simulation
* Focus only on the DMG model

## Code Style
- Follow best practice of Rust
